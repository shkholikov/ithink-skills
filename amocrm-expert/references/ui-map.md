# Where things are in amoCRM

Left sidebar and settings paths as they usually appear in the Russian
interface. amoCRM moves things between releases: if a label differs on screen,
trust the screen and tell him the path you actually used.

| What | Path |
|---|---|
| Deals, pipelines | Сделки (воронка selector at the top) |
| Pipeline stages, Digital Pipeline triggers, Salesbots per stage | Сделки → «Настроить» (or «Автоматизировать») on the pipeline |
| Salesbot list and editor | Сделки → Настроить → stage → Salesbot; also Настройки → Salesbot (in some accounts) |
| Неразобранное (incoming unsorted) | first column of the pipeline; on/off in pipeline settings |
| Contacts and companies | Списки → Контакты / Компании |
| Tasks | Задачи |
| Chats, conversations | Чаты |
| Analytics, reports | Аналитика |
| Widgets, integrations, amoMarket | Настройки → Интеграции (amoMarket catalog and installed list) |
| Widget settings | Настройки → Интеграции → widget tile → its settings window |
| Custom fields | Настройки → Поля (by entity: сделки, контакты, компании) |
| Users, groups, rights | Настройки → Пользователи |
| Account settings, plan, payment | Настройки → Общие настройки / Оплата |
| Duplicate control | Настройки → Контроль дублей (in some plans) |
| Event log | Списки / Аналитика → События; the deal card's own feed |
| Private integrations, API keys | Настройки → Интеграции → «Создать интеграцию» (admin only) |

Account identity: subdomain in the address bar (`{client}.amocrm.ru`) and the
account name at the top of the left sidebar menu.
