# Установка навыков в приложение Claude

Инструкция для сотрудников ITHINK. Быть разработчиком не нужно —
ни терминал, ни `git` не понадобятся. Занимает около 3 минут.

Навык (skill) — это дополнительная компетенция, которую вы добавляете
Claude. После установки Claude умеет строить схемы сети, диаграммы
систем, готовить документы ITHINK и помогать с настройкой amoCRM.

**Понадобится:** подписка Claude Pro и аккаунт на
[claude.ai](https://claude.ai).

---

## Шаг 1 — скачайте файлы

Откройте [страницу Releases](https://github.com/shkholikov/ithink-skills/releases/latest)
и в разделе **Assets** под самым верхним релизом скачайте нужные
`.zip`-файлы:

| Файл | Что делает |
|---|---|
| `topology-creator-skill.zip` | Схема сетевой топологии — иконки Cisco, цвета VLAN, подписи портов. На выходе файл draw.io, его можно редактировать |
| `system-diagram-skill.zip` | Диаграмма системы или процесса — SVG, анимированный SVG и GIF |
| `ithink-documents-skill.zip` | Документы ITHINK для клиентов — коммерческие предложения, презентации, технические предложения |
| `amocrm-expert-skill.zip` | Помощник интегратора amoCRM — диагностика и настройка виджетов (Wazzup, OnlinePBX, Zadarma), Salesbot, воронок. Ничего не меняет без вашего «да» |

Можно скачать все или только нужные.

> В списке Assets также есть **Source code** (zip и tar.gz) — их скачивать
> не нужно. Это копия всего проекта, а не навык; Claude её не примет.
> Нужны только файлы `-skill.zip` из таблицы выше.

> **Не распаковывайте** архив. Он загружается в Claude именно в виде
> `.zip`. Safari на macOS может распаковать архив автоматически — тогда
> нажмите на папку в Загрузках правой кнопкой и выберите «Сжать», чтобы
> снова получить `.zip`.

## Шаг 2 — загрузите в Claude

1. Зайдите на [claude.ai](https://claude.ai) (или откройте приложение Claude Desktop)
2. Нажмите на своё имя внизу слева → **Settings**
3. Перейдите в **Capabilities** → **Skills**
4. Нажмите **Upload skill**
5. Выберите `.zip`-файл, скачанный на шаге 1
6. Повторите шаги 4–5 для каждого навыка

Убедитесь, что навык появился в списке и включён.

## Шаг 3 — проверьте, что работает

Откройте новый чат и напишите примерно так:

> У меня 2 коммутатора, 1 роутер и 10 компьютеров. Нарисуй схему этой сети.

Claude сам выберет нужный навык — называть его не требуется. В ответе
должен появиться файл, который можно скачать.

Другие примеры:

> Сделай диаграмму того, как работает наша платёжная система
>
> Подготовь коммерческое предложение для клиента по обновлению серверной инфраструктуры
>
> (на открытой странице amoCRM) Почему в сделки перестали приходить сообщения из WhatsApp?

## Все навыки одной установкой (Cowork)

Вместо загрузки каждого `.zip` можно подключить весь репозиторий как
плагин — тогда все навыки ставятся сразу и обновляются сами.

1. Откройте Claude Desktop → вкладка **Cowork** → **Customize**
2. Вкладка **Plugins** → **+** (Add) → **Add marketplace** → **Add from a repository**
3. Введите `shkholikov/ithink-skills`
4. Во вкладке **Discover** найдите плагин **ithink** и нажмите **Install**
5. Включите **Sync automatically**, чтобы получать новые версии без ручной загрузки

Если пункта Add marketplace нет — используйте загрузку `.zip` из шагов 1–2.

## amoCRM-эксперт в Chrome

Навык рассчитан на работу в расширении **Claude in Chrome**, прямо на
странице `{клиент}.amocrm.ru`.

1. Установите расширение Claude из
   [Chrome Web Store](https://chromewebstore.google.com/detail/claude/fcoeoabgfenejglbffodgkkbkcdhcgfn)
   и войдите в свой аккаунт Claude
2. В настройках расширения выберите режим **Manually approve** (ручное
   подтверждение) — Claude будет спрашивать разрешение перед каждым
   действием на странице. Это вторая защита поверх правил самого навыка
3. Убедитесь, что навык `amocrm-expert` (или плагин **ithink**) включён —
   навыки и плагины аккаунта доступны в боковой панели Chrome
4. Откройте аккаунт клиента и напишите в боковой панели: «В каком
   аккаунте мы работаем и какие виджеты здесь установлены?»

Как он работает:

- Сначала называет аккаунт клиента, в котором открыта вкладка
- Сам только читает: открывает настройки, виджеты, сделки, ищет причину
- Перед любым изменением показывает **карточку изменения**: что именно,
  какие последствия (Salesbot, триггеры, сообщения клиентам), кого
  затронет, как откатить
- Делает изменение только после вашего явного «да»
- Логины, пароли и ключи вводите сами — Claude их не вводит

## Обновление

Навык хранится в вашем аккаунте Claude — не на компьютере, а на сервере
Anthropic, и только для вас. Отсюда три следствия:

- **Автоматически не обновляется.** Когда мы выпускаем новую версию, ваша
  копия остаётся старой — нужно загрузить заново вручную.
- **claude.ai и Claude Desktop — отдельно.** Если пользуетесь обоими,
  загрузите навык в каждом.
- **Чтобы узнать текущую версию**, спросите Claude: «какая у тебя версия
  навыка topology-creator?». Сравните ответ с номером на
  [странице Releases](https://github.com/shkholikov/ithink-skills/releases/latest).

Порядок обновления:

1. Скачайте новый `.zip` со страницы Releases
2. В Settings → Capabilities → Skills **удалите старый навык**
3. Загрузите новый `.zip`
4. **Откройте новый чат.** Claude читает список навыков в начале разговора,
   поэтому в уже открытом чате останется старая версия

## Если что-то не работает

**Навыка нет в списке.** Обновите страницу. В Claude Desktop полностью
закройте приложение и откройте заново.

**Ошибка «Invalid skill package».** Архив собран неправильно — скорее
всего вы его распаковали и заархивировали заново. Скачайте файл со
страницы Releases ещё раз и загрузите без изменений.

**Claude не использует навык.** Скажите прямо: «используй навык
topology-creator и нарисуй эту сеть».

**Вышла новая версия.** В Settings → Capabilities → Skills удалите
старый навык и загрузите новый `.zip`.
